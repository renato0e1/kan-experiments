# kan-experiments

Artigo: Redes de Kolmogorov–Arnold: Uma Avaliação Experimental com LunarLander

Autores: Renato França de Almeida - PPGEEC EMC/UFG

Notebooks de implementação de experimentos em DRL realizados com MLP e redes derivadas da KAN usando ambiente LunarLander-v3:
#### LunarLanderMLP_9_8.ipynb: implementação MLP (Multilayer Perceptron)
#### LunarLanderFastKAN_10_3.ipynb: implementação FastKAN (Fast Kolmogorov-Arnold)
#### LunarLanderKKAN_2_5.ipynb: implementação KKAN (Kurkova-Kolmogorov-Arnold)
